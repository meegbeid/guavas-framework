# Berkontribusi ke Guavas

Terima kasih sudah membantu mengembangkan Guavas. Usulkan perubahan kecil dan terarah agar mudah ditinjau.

## Sebelum mengirim perubahan

1. Jelaskan masalah yang ingin diselesaikan dan perilaku yang diharapkan.
2. Pertahankan kontrak publik yang sudah dipakai aplikasi lain, atau jelaskan perubahan kompatibilitasnya.
3. Jalankan `composer validate` dan pemeriksaan sintaks PHP pada file yang diubah.
4. Jika mengubah alur instalasi, uji `composer create-project` dari paket lokal.
5. Jangan sertakan kredensial, file `.gv` hasil inisialisasi, isi `storage/`, atau data pelanggan.

Komponen pihak ketiga harus disertai sumber, versi, dan informasi lisensinya. Lihat [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
